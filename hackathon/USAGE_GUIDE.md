# AI-TOP-100 해커톤 에이전트 실전 사용 가이드

이 문서는 심사위원이나 사용자가 **슬래시 명령어(`/위임` 등) 없이 일반 자연어로만 질문**하더라도, 내부 자동 라우터(`hackathon/router.py`)가 문제를 분류해 **로컬 `qwen3.8`**과 **VS Code(`Codex` / `Gemini`)**로 자동 분기하는 실전 매뉴얼입니다.

---

## 1. 심사위원 자연어 질문 시 내부 자동 분기 흐름 (3단계)

심사위원이 카카오톡 챗봇에 일반 문장으로 질문하면 **`hackathon/router.py`**가 0.1~1초 내에 아래 3가지 경로 중 하나로 자동 분기합니다.

1. **`SOLUTION_HIT` (사전 풀이 적중 — 1~3초 내 응답)**
   - 질문에 포함된 키워드가 `hackathon/solutions/` 폴더의 사전 검증 해답과 일치하면, 로컬 `qwen3.8`이 재계산 없이 해당 정답을 바탕으로 자연스럽게 답변합니다.
2. **`SIMPLE` (단순 질문 — 로컬 `qwen3.8` 즉시 응답)**
   - 도시 상태 확인, 단답형 사실 조회, 간단한 확인 질문은 로컬 `qwen3.8`이 직접 도구를 사용해 즉시 답변합니다.
3. **`COMPLEX` (고난도 문제 — 자동으로 `inbox.md` 생성 + 무결점 폴백)**
   - `최적`, `경로`, `스케줄`, `배치`, `시뮬레이션`, `모순`, `범인`, `비교 분석` 등 고난도 키워드나 복합 조건이 포함된 질문은 **자동으로 `hackathon/queue/inbox.md`에 등록**되고, 서버 터미널에 `🔔 [고난도 문제 자동 감지]` 알림이 뜹니다.
   - **120초 이내**에 VS Code(Codex/Gemini)에서 `inbox 풀어줘`를 실행해 `outbox.md`가 저장되면, **아무런 내부 태그 없이 Codex/Gemini의 순수 답변만 심사위원에게 즉시 전송**됩니다.
   - 만약 **120초가 지나도** 사람이 `outbox.md`를 저장하지 못하면, 심사위원이 빈손으로 기다리지 않도록 **로컬 `qwen3.8`이 자동으로 폴백(Fallback) 실행되어 카카오 콜백 만료(300초) 전에 최선의 답변을 먼저 전송**합니다. (이후 `outbox.md`가 완성되면 카카오톡 방으로 정밀 답변이 한 번 더 자동 푸시됩니다.)

---

## 2. 대회 시작 전 서버 실행 방법

터미널 창을 하나 열어 서버를 켜둡니다. 고난도 질문이 들어오면 이 터미널에 `🔔 [고난도 문제 자동 감지]` 배너가 출력됩니다.

```bash
uv run anyagents
```

---

## 3. 대회 당일 시간대별 실전 워크플로우

### Step 1. 대회 시작 직후: 초기 세계관·데이터 세팅 (1회 대화)

1. 대회에서 제공된 파일(CSV, JSON, 로그, 텍스트 등)을 **`hackathon/data/`** 폴더에 넣습니다.
2. VS Code(Gemini 또는 Codex 채팅창)에 문제 설명/초기 단서를 붙여넣고 아래처럼 입력합니다.

> **VS Code (Codex / Gemini) 입력 프롬프트:**
> ```text
> hackathon/AGENTS.md 절차에 따라 아래 초기 브리핑과 hackathon/data/ 파일들을 확인해서 해커톤 세팅 업데이트해줘.
> (여기에 대회 문제 설명/단서 붙여넣기)
> ```

---

### Step 2. 예상 문제 미리 풀어두기 (`hackathon/solutions/` 활용)

대회 문제를 읽고 심사위원이나 평가에서 물어볼 핵심 문제들을 VS Code(Codex / Gemini)로 먼저 풀어둡니다.

> **VS Code 입력 프롬프트:**
> ```text
> 지금 문제(예: A구역 전력 복구 최적 경로)를 파이썬으로 검증해서 풀고,
> 새로 나온 단서는 hackathon/world_state.json에 업데이트하고,
> 최종 풀이 결과는 hackathon/solutions/ 폴더에 저장해줘.
> ```

- 이렇게 저장해 두면 심사위원이 관련 질문을 던졌을 때 **`SOLUTION_HIT` 경로가 작동하여 사람 개입 없이 100% 검증된 정답이 자동으로 나갑니다.**

---

### Step 3. 실시간 심사/질의응답 중: 터미널 알림 보고 한 줄 입력

미리 풀어두지 않은 새로운 고난도 질문이 카카오톡으로 들어오면:

1. 서버 터미널에 **`🔔 [고난도 문제 자동 감지 -> hackathon/queue/inbox.md 생성됨]`** 알림이 뜹니다.
2. **VS Code(Codex 또는 Gemini 채팅창)**에 아래 한 마디만 입력합니다.
   ```text
   inbox 풀어줘
   ```
3. Codex/Gemini가 `hackathon/queue/outbox.md`를 저장하는 순간 카카오톡으로 깔끔한 최종 답변이 자동 발송됩니다.

---

## 4. 라우팅 모드 강제 전환 스위치 (필요 시)

상황에 따라 자동 분류 대신 **모든 질문을 무조건 Codex/Gemini 큐로 보내거나**, 반대로 **모든 질문을 무조건 로컬 `qwen3.8`이 직접 풀게** 하고 싶다면 `hackathon/world_state.json` 상단에 `"routing_mode"` 한 줄만 넣으면 즉시 적용됩니다.

- `"routing_mode": "auto"` (기본값: 단순 질문은 로컬, 고난도 질문은 `inbox.md` 자동 분기)
- `"routing_mode": "always_heavy"` (모든 질문을 무조건 `inbox.md`로 전달)
- `"routing_mode": "always_local"` (모든 질문을 로컬 `qwen3.8`이 즉시 직접 응답)

---

## 5. VS Code (Codex / Gemini) 단축 프롬프트 요약

| 상황 | VS Code 채팅창에 입력할 문장 |
| :--- | :--- |
| **초기 세계관/단서 입수 시** | `"이 단서들로 해커톤 세팅 업데이트해줘: [단서 내용]"` |
| **터미널에 `🔔 고난도 문제 감지`가 떴을 때** | `"inbox 풀어줘"` 또는 `"/solve-inbox"` |
| **특정 문제를 미리 풀어 저장해 둘 때** | `"[문제 내용]을 파이썬으로 검증해서 풀고 hackathon/solutions/에 저장해줘"` |
| **새로운 단서만 추가할 때** | `"방금 확인된 [단서 내용]을 world_state.json에 반영해줘"` |

---

## 6. 해커톤 종료 후 정리 방법 (AnyArchive 전환)

대회 종료 후 아래 명령어 한 줄만 실행하면 해커톤 관련 파일이 모두 제거되고 **AnyArchive 고객 문의 챗봇**으로 즉시 전환됩니다.

```bash
rm -rf hackathon .agents/skills/hackathon-briefing .agents/skills/solve-inbox
```
